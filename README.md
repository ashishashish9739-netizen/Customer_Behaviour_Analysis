# Customer Behaviour Analysis

## 1. Overview
This project focuses on analyzing customer shopping behaviour to identify purchasing patterns, sales trends, revenue distribution, and customer preferences. It uses Python for data cleaning, MySQL for database management and SQL analysis, and Power BI for interactive dashboard creation.

## 2. Dataset
The project uses a Customer Shopping Behaviour dataset containing information such as:
- Customer ID and Age
- Gender and Age Group
- Product Category
- Purchase Amount
- Review Rating
- Subscription Status
- Shipping Type
- Payment Method

## 3. Tools & Technologies
- **Python:** Data loading, cleaning, preprocessing, and Exploratory Data Analysis (EDA).
- **MySQL:** Database management and SQL queries for data analysis.
- **Power BI:** Interactive dashboard and data visualization.
- **Gamma:** Presentation creation.
- **Microsoft PowerPoint:** Project presentation.

## 4. Project Steps
1. Loaded the dataset using Python.
2. Performed Exploratory Data Analysis (EDA).
3. Cleaned and preprocessed the dataset.
4. Imported the cleaned data into MySQL.
5. Executed SQL queries to analyze customer behaviour and purchasing trends.
6. Connected the analyzed data to Power BI.
7. Created an interactive dashboard using charts, KPI cards, and slicers.
8. Prepared a project report and presentation using Gamma.

## 5. Dashboard
The Power BI dashboard includes:
- Total Number of Customers
- Average Purchase Amount
- Average Review Rating
- Percentage of Customers by Subscription Status
- Revenue by Category
- Sales by Category
- Revenue by Age Group
- Sales by Age Group
- Interactive slicers for customer segmentation.

## 6. Results
The analysis provides insights into customer purchasing behaviour, category-wise revenue, sales distribution, age-group preferences, and subscription patterns. The interactive dashboard helps present these insights in a clear and understandable format.

## 7. How to Run
1. Download or clone this repository.
2. Install the required Python libraries.
3. Load the dataset into Python.
4. Run the Python scripts for data cleaning and EDA.
5. Import the cleaned dataset into MySQL.
6. Execute the SQL queries provided in the project.
7. Open the Power BI file (.pbix) to explore the dashboard.

## 8. Conclusion
This project demonstrates the use of Python, MySQL, and Power BI in a complete data analytics workflow, from raw data processing to extracting insights and presenting them through interactive visualizations.
